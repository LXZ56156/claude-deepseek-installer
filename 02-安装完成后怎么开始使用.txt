Claude Code + DeepSeek API 本地配置助手 v1.3.3
安装完成后怎么开始使用

======================================================================
一、先确认安装成功
======================================================================

新开一个 PowerShell 或 Windows Terminal 窗口（不要用安装时那个窗口），输入：

    claude --version

如果能看到版本号，说明安装成功。版本号具体数字会随 Claude Code 更新而变化，不用在意具体显示什么。

再输入：

    claude

如果能进入 Claude Code 交互界面，说明配置完全正确。

======================================================================
二、打开 Claude Code 的最简单方法
======================================================================

1. 按 Win + R，输入 powershell，回车。
2. 在 PowerShell 窗口里输入 claude，回车。
3. 第一次启动可能需要稍等几秒。
4. 第一次启动如果出现目录信任确认提示，请确认当前目录是你自己的项目文件夹，然后按提示操作。

======================================================================
三、在自己的项目里使用
======================================================================

1. 先进入你的项目文件夹：

    cd "你的项目路径"

   比如路径中有空格时，需要用引号括起来：

    cd "D:\My Projects\demo"

2. 在项目文件夹里运行：

    claude

3. Claude Code 会自动读取项目里的文件来分析项目结构。

重要提示：

- 不建议直接在用户主目录（C:\Users\你的用户名）运行 claude 让 AI 大范围修改文件。
- 也不建议在有重要文件的目录（如桌面、文档）直接让 AI 修改。
- 建议先进入具体的项目文件夹，再启动 claude。

======================================================================
四、第一次建议复制的提示词
======================================================================

如果你是第一次使用 Claude Code，建议先复制下面这段提示词：

    我是 Windows 用户，刚安装好 Claude Code + DeepSeek。请你先不要直接写项目代码，先检查当前目录和我的开发环境。请按下面顺序执行：

    1. 判断当前目录是否是一个项目目录。
    2. 检查是否有 package.json、requirements.txt、pyproject.toml、go.mod、pom.xml 等依赖文件。
    3. 判断这个项目大概是什么技术栈。
    4. 告诉我当前缺少哪些开发依赖。
    5. 给我一份"最小可运行环境"的安装建议。
    6. 不要一次性乱装很多东西，先列计划，等我确认后再执行。

更多提示词模板请看：03-常用提示词模板.txt

======================================================================
五、没有开发环境怎么办
======================================================================

如果你只是想试试 Claude Code，可以先这样做：

1. 新建一个空文件夹，进入后运行 claude。
2. 告诉 Claude Code 你想做什么，它会建议你需要安装什么。
3. 让 AI 先判断需要什么环境，再决定装不装。

======================================================================
六、Windows 和 WSL 是两套独立环境
======================================================================

Windows 和 WSL（Linux 子系统）是两套独立的环境，配置不共享：

- 本工具安装的是 Windows 版 Claude Code，在 PowerShell 或 CMD 中使用。
- 如果你在 WSL Ubuntu 终端中使用 claude，那是另一套安装，与本工具无关。
- 两边的 settings.json 不是同一个文件。
- 两边的 Claude Code 需要分别安装和配置。

======================================================================
七、VS Code 是可选项
======================================================================

- 你不需要安装 VS Code 就能使用 Claude Code。
- 在 PowerShell 命令行里直接输入 claude 就是全部操作。
- 如果你习惯用 VS Code，可以装，但本工具不强制。

======================================================================
八、微信小程序怎么开始
======================================================================

- 微信小程序的预览、调试、上传必须在微信开发者工具中完成。
- Claude Code 可以帮助你：写代码、解释项目结构、生成页面和组件、排查 bug。
- 但仍然需要你在微信开发者工具里点击"预览"或"上传"。
- 建议先用 Claude Code 分析项目结构，再决定要做什么。

======================================================================
九、网页/前端项目怎么开始
======================================================================

1. 进入网页项目文件夹，运行 claude。
2. 告诉它："帮我检查这个前端项目的结构和依赖"。
3. 让 AI 先判断是 HTML 静态项目还是 Vue/React 框架项目。
4. 确认 Node.js 和 npm 是否已安装。
5. 没有 Node.js 的话，可以让 AI 给你安装命令，或者参考提示词模板目录中的 02-补装开发环境和依赖.txt。

======================================================================
十、Python 脚本怎么开始
======================================================================

1. 进入脚本所在文件夹，运行 claude。
2. 告诉它："帮我分析这个 Python 脚本的作用"。
3. 让 AI 检查是否缺少依赖包，先列清单，不要直接安装。
4. 建议用虚拟环境（venv）隔离不同项目的依赖。

======================================================================
十一、安全使用建议
======================================================================

- 不要把完整 API Key 复制粘贴发给 AI。
- 不要让 AI 直接读取或输出 settings.json 原文。
- 让 AI 修改代码前，先让它列出要改的文件和修改计划。
- 每次只解决一个明确的问题，不要一次塞很多需求。
- 改完代码后，先让 AI 告诉你如何测试。

======================================================================
十二、出问题怎么找卖家
======================================================================

1. 在解压后的文件夹里双击：一键诊断.cmd
2. 诊断完成后，优先发送 support-feedback.txt。
3. 如果没有 support-feedback.txt，再发送 report.txt。
4. 不要只发截图，截图只能作为补充。
5. 不要发送完整 API Key。
6. 不要发送 settings.json。
7. 不要发送 backup/、logs/、reports/、full-report-*。

更多问题请看：04-常见问题和售后.txt

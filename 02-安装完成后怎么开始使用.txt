Claude Code 第一次使用说明
============================================================

先认识三个词
============================================================

终端：输入命令的窗口，例如 PowerShell 或 Windows Terminal。
工作目录：终端当前所在的文件夹，Claude Code 会从这里读取你的项目。
PATH：Windows 用来查找 claude 等命令的位置列表；安装后旧终端可能还没有刷新它。

确认安装结果
============================================================

1. 关闭安装前打开的旧终端。
2. 新开 PowerShell 或 Windows Terminal。
3. 输入：

   claude --version

4. 能显示版本号后输入：

   claude

如果提示 claude 命令不存在，先关闭窗口并再新开一个终端。仍然失败时，
回到工具文件夹双击 一键诊断.cmd。

在自己的项目文件夹中启动
============================================================

推荐方式：

1. 在文件资源管理器中打开你自己的项目文件夹。
2. 点击顶部地址栏。
3. 输入：

   powershell

4. 按回车，系统会在这个项目文件夹打开终端。
5. 输入：

   claude

备用方式是在终端用 cd 进入项目。例如：

   cd D:\work\demo

路径包含空格时必须加引号：

   cd "D:\My Projects\demo"

不要把自己的项目创建在安装工具目录、ZIP 预览目录或系统临时目录。
只有确认终端当前位于正确的项目文件夹时，才允许 Claude Code 读取项目文件。
不要在用户主目录、磁盘根目录、桌面总目录或包含大量无关文件的上级目录直接运行 claude。

第一次使用建议
============================================================

Claude Code 可能询问是否允许读取、修改或执行操作。只读操作也不是绝对安全，
权限确认前要检查当前目录和操作范围。

1. 不要让 Claude Code 无目的读取 .env、settings.json、credentials、私钥、Cookie、
   密码文件、生产数据或客户隐私数据。
2. 如果必须检查配置，优先只检查字段名称和结构，不输出完整值，并对敏感值脱敏。
3. 修改文件前看清它准备修改的范围。
4. 安装软件、删除文件或修改系统设置时要谨慎确认。

推荐顺序是：先让 AI 检查项目，再看它给出的计划，确认范围后才允许修改，
最后要求它实际运行适合项目的测试。

最简单的首次提示词示例：

   请先只读检查当前项目，告诉我它是什么、如何启动、有哪些风险。
   先给计划，不要修改文件，等我确认后再继续。

Windows 和 WSL
============================================================

Windows 与 WSL 是两套独立环境，安装的软件、命令路径和配置不会自动共享。
请在你实际使用项目的那一套环境里运行 claude；不要在 Windows 安装后，
直接假设 WSL 中也已经可用。

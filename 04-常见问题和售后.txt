常见问题和售后
============================================================

先按症状排查。不要重复安装，不要随意删除配置，也不要把一键修复依赖
当作所有问题的第一反应。诊断入口不是完整安装入口。

ZIP 和启动问题
============================================================

1. ZIP 无法打开或文件缺失
   重新下载完整 ZIP，确认下载完成后再“全部解压”。不要自行补文件或改名。

2. 在 ZIP 预览窗口运行失败
   先完整解压到普通文件夹，再从解压后的文件夹运行。

3. 双击安装入口没有反应
   确认文件已解压，先用 00-点我开始安装.cmd；仍无反应时改用 Start-Install.cmd。

4. 中文入口乱码
   使用英文备用入口 Start-Install.cmd。默认以普通用户身份运行，
   不要把管理员权限作为通用修复。

安装窗口问题
============================================================

5. 安装窗口持续运行
   安装时间取决于网络和电脑。有持续进度时继续等待，不要重复双击，也不要直接关闭窗口。

6. 安装窗口长时间没有新输出
   先确认窗口是否仍有下载或进度变化。没有变化时记录最后几行文字，
   不要反复安装，按本文末尾的售后分流运行诊断。

命令和输入问题
============================================================

7. claude 命令不存在
   关闭旧终端，新开 PowerShell 或 Windows Terminal，再运行 claude --version。
   仍失败时运行 一键诊断.cmd。

8. API Key 输入看不到字符
   这是正常的安全保护。输入或粘贴后按回车即可，不要为了确认而公开 Key。

API 错误码
============================================================

API 错误不等于安装失败。Claude Code 能启动，说明安装部分可能已经完成。

9. 400：请求格式不正确。根据错误信息检查请求体格式。
10. 401：API Key 错误或认证失败。请核对自己的 API Key。
11. 402：账户余额不足。请到 DeepSeek 官方平台检查余额。
12. 422：请求参数不合法。根据错误信息检查参数、模型和请求内容。
13. 429：请求过快、并发或限流问题。请降低请求速度后重试。
14. 500：DeepSeek 服务端错误，请稍后重试；持续发生时查看官方状态或联系官方支持。
15. 503：DeepSeek 服务过载，请稍后重试。
16. 403：可能来自账户权限、兼容层、网络安全策略或自定义 API 地址，
   不能直接断定是 DeepSeek API Key 被限制。
17. 404：可能来自 Base URL、兼容路径、模型名称或自定义网关，
   不能直接断定是 DeepSeek 官方接口不存在。
18. 5xx：服务端错误总类，至少包括 500 和 503；先稍后重试，再根据具体错误处理。

项目和环境问题
============================================================

19. Claude Code 能启动，但项目运行失败
   这通常是项目自身的依赖、配置或代码问题，不代表安装失败。先让 AI 只读检查项目。

20. Node.js、npm 或项目依赖缺失
   只有明确是 Node.js、npm 或 Claude Code 依赖缺失时，才运行 一键修复依赖.cmd。
   项目自身依赖仍应按项目实际说明安装，并在执行前确认。

21. Windows 与 WSL 混用
   两者是独立环境，命令、安装和配置不自动共享。请在实际使用项目的环境中分别检查。

配置管理
============================================================

22. 重新配置 API Key
   双击 00-点我开始安装.cmd，在菜单中选择配置 DeepSeek API Key 的选项，
   或按工具菜单提示进入配置。不要把 Key 发给售后。

23. 恢复或卸载配置
   双击 恢复或卸载配置.cmd，按菜单选择恢复备份、移除 Key 或删除工具配置。
   操作前看清说明，不要手动删除 settings.json。

联系售后
============================================================

第一步：不要重复安装，不要随意删除配置。

第二步：如果明确是 Node.js、npm 或 Claude Code 依赖缺失，运行：

   一键修复依赖.cmd

第三步：仍然失败，运行：

   一键诊断.cmd

第四步：只发送本工具解压目录中的售后文件，也就是与 一键诊断.cmd 同一个文件夹。
优先发送该文件夹中的 support-feedback.txt；如果没有，再发送同一文件夹中的 report.txt 作为备用。

不要只发截图，截图只能作为补充。发送截图前检查是否包含完整 Key。

不要发送完整 API Key。
不要发送 settings.json。
不要发送以下目录或文件：

1. backup/。
2. logs/。
3. reports/ 目录中的任何文件。
4. 私钥、密码或 Cookie。
5. 其他包含敏感信息的文件。

即使 reports/ 中某些文件已经脱敏，普通售后也不要求发送整个目录，
避免误把完整版或不必要的历史记录一起发送。

本工具不提供 Claude 账号、DeepSeek API Key、代理 API、VPN 或网络加速。

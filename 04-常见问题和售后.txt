# 常见问题和售后

## 1. 安装类问题

### 为什么双击 00-点我开始安装.cmd 没有反应？
- 可能出现了安全提示窗口，被挡在其他窗口后面了。
- 检查任务栏是否有新的命令行窗口。
- 右键点击文件，选择"以管理员身份运行"试试。

### 为什么提示"请先完整解压 ZIP"？
- 你在压缩包预览窗口里直接双击了文件。
- 正确的做法是：先把 ZIP 完整解压到一个普通文件夹，再双击里面的文件。
- 在 Windows 资源管理器里，右键 ZIP → "全部解压"。

### 怎么判断安装有没有成功？
- 新开一个 PowerShell 窗口，输入 `claude --version`。
- 如果显示版本号，就是成功了。
- 如果显示"找不到命令"，说明安装没完成，请运行一键诊断.cmd。

### 安装过程中卡住了怎么办？
- 下载和安装可能需要 2-5 分钟，请耐心等待。
- 如果超过 10 分钟没有变化，可以关闭窗口重新运行。

## 2. API Key 类问题

### 输入 Key 时不显示字符是正常的吗？
- 完全正常。这是安全保护，输入的字符不会显示在屏幕上。
- 直接粘贴后按回车就行。

### 没有 DeepSeek API Key 怎么办？
- 去 https://platform.deepseek.com 注册账号，然后创建 API Key。
- 本工具不提供 DeepSeek API Key，用户需自备。

### API 测试失败是不是安装失败了？
- 不一定。安装和 API 测试是分开的步骤。
- 如果安装成功但 API 测试失败，通常是 Key 本身的问题（过期、余额不足、复制错误）。
- 重新运行一次配置：双击 00-点我开始安装.cmd，选择配置 Key。

### 401 错误是什么意思？
- API Key 无效或未提供。请检查 Key 是否正确复制，是否过期。

### 402 错误是什么意思？
- DeepSeek 账户余额不足。请充值后再试。

### 403 错误是什么意思？
- 访问被拒绝。Key 可能没有权限，或者被限制了。

### 404 错误是什么意思？
- 请求的接口不存在。可能是模型名称或 API 地址配置错误。

### 429 错误是什么意思？
- 请求频率过高。等几秒再试。

### 5xx 错误是什么意思？
- DeepSeek 服务器端问题。等几分钟再试，或查看 DeepSeek 官方状态页面。

## 3. 使用类问题

### 输入 claude 显示"找不到命令"怎么办？
- 可能是 PATH 环境变量没有生效。
- 关掉当前 PowerShell 窗口，新开一个再试。
- 如果还是不行，在解压文件夹里双击 一键诊断.cmd。

### 没有 VS Code 能不能用？
- 能。Claude Code 是命令行工具，在 PowerShell 里直接输入 `claude` 就用。
- VS Code 是可选工具，不装也不影响本工具的使用。

### Windows 和 WSL 是不是同一套环境？
- 不是。Windows 版 Claude Code 和 WSL（Linux 子系统）是两套独立的环境。
- 本工具安装的是 Windows 版本，在 PowerShell 里使用。
- 如果你在用 WSL，需要单独在 WSL 里安装 Claude Code。

## 4. 错误码速查

| 错误码 | 大概含义 | 怎么办 |
|--------|---------|--------|
| 401 | API Key 无效 | 检查 Key 是否正确、是否过期 |
| 402 | 余额不足 | 充值 DeepSeek 账户 |
| 403 | 权限拒绝 | 检查 Key 权限设置 |
| 404 | 接口不存在 | 检查模型名称和 API 地址 |
| 429 | 请求太频繁 | 等几秒再试 |
| 5xx | 服务器错误 | 等几分钟再试，或查 DeepSeek 状态 |

## 5. 诊断和售后流程

如果遇到问题，请按以下步骤操作：

1. 先不要重复安装。
2. 在解压后的文件夹里双击 一键诊断.cmd。
3. 运行完成后，会在文件夹里生成 support-feedback.txt 和 report.txt。
4. 优先发送 support-feedback.txt 给卖家。
5. 如果没有 support-feedback.txt，再发送 report.txt。
6. 不要只发截图。
7. 不要发送完整 API Key。
8. 不要发送 settings.json。
9. 不要发送 backup/、logs/、reports/、full-report-*。

## 6. 哪些文件可以发给卖家

- support-feedback.txt（优先）
- report.txt（没有 support-feedback 时才发）
- 错误信息的截图（确认截图里没有完整 API Key）

## 7. 哪些文件不要发

- settings.json
- backup/ 目录下的任何文件
- logs/ 目录下的任何文件
- reports/ 目录下的 full-report-*
- 任何包含完整 API Key 的内容

## 8. Windows 和 WSL 的区别

- 本工具安装在 Windows 系统上，使用 Windows 版 Claude Code。
- WSL（Windows Subsystem for Linux）是 Windows 里的 Linux 子系统。
- 如果你在 WSL 里也需要 Claude Code，需要单独在 WSL 里安装。
- Windows 版和 WSL 版的 settings.json 是独立的，需要分别配置。

## 9. 本工具提供什么 / 不提供什么

本工具提供：
- 自动安装 Claude Code（Windows 版）
- 自动配置 DeepSeek API 作为 Claude Code 的模型后端
- 一键诊断工具，帮助排查问题
- 使用指南和常用提示词模板

本工具不提供：
- 不提供 Claude 账号
- 不提供 DeepSeek API Key
- 不提供代理 API
- 不提供 VPN 或网络加速服务
- DeepSeek API 使用费用由用户自己的 DeepSeek 账户承担
- Claude Code 本身是 Anthropic 的产品，本工具只负责安装和配置

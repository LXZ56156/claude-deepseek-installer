Claude Code + DeepSeek API 本地配置助手 v1.3.3
常见问题和售后

======================================================================
一、安装类问题
======================================================================

问：为什么双击 00-点我开始安装.cmd 没有反应？

- 先确认 ZIP 已经完整解压到普通文件夹，不是在压缩包预览窗口里。
- 检查任务栏是否有新的命令行窗口，可能被挡在其他窗口后面。
- 检查是否有安全软件的拦截提示。
- 如果中文文件名显示乱码，请使用英文备用入口 Start-Install.cmd。
- 以上都试过仍无反应，请运行一键诊断.cmd 生成诊断文件。
- 不要一上来就以管理员身份运行。

问：为什么提示"请先完整解压 ZIP"？

- 你在压缩包预览窗口里直接双击了文件。
- 正确的做法是：先把 ZIP 完整解压到一个普通文件夹，再双击里面的文件。
- 在 Windows 资源管理器里，右键 ZIP → "全部解压"。

问：怎么判断安装有没有成功？

- 新开一个 PowerShell 窗口，输入 claude --version。
- 如果显示版本号，就是成功了。
- 如果显示"找不到命令"，说明安装没完成，请运行一键诊断.cmd。

问：安装过程中好像卡住了怎么办？

- 安装时间取决于网络和电脑环境，请耐心等待。
- 只要窗口持续出现新的进度提示，就继续等待。
- 不要在安装过程中重复双击安装入口。
- 不要在正在安装时直接关闭窗口。
- 如果长时间完全没有任何新输出，记录窗口显示的内容，然后运行一键诊断.cmd。
- 出现明确的超时或失败提示后，再按提示操作。

======================================================================
二、API Key 类问题
======================================================================

问：输入 Key 时不显示字符是正常的吗？

- 完全正常。这是安全保护，输入的字符不会显示在屏幕上。
- 直接粘贴后按回车就行。

问：没有 DeepSeek API Key 怎么办？

- 去 https://platform.deepseek.com 注册账号，然后创建 API Key。
- 本工具不提供 DeepSeek API Key，用户需自备。

问：API 测试失败是不是安装失败了？

- 不一定。安装和 API 测试是分开的步骤。
- 如果安装成功但 API 测试失败，通常是 Key 本身的问题（过期、余额不足、复制错误）。
- 重新运行安装入口并选择配置相关选项，重新输入 Key。

问：401 错误是什么意思？

- API Key 无效或未提供。请检查 Key 是否正确复制、是否过期。

问：402 错误是什么意思？

- DeepSeek 账户余额不足。请充值后再试。

问：403 错误是什么意思？

- 访问被拒绝。Key 可能没有权限，或者被限制了。

问：404 错误是什么意思？

- 请求的接口不存在。可能是模型名称或 API 地址配置错误。

问：429 错误是什么意思？

- 请求频率过高。等几秒再试。

问：5xx 错误是什么意思？

- DeepSeek 服务器端问题。等几分钟再试，或查看 DeepSeek 官方状态页面。这不是您的配置问题。

问：怎么重新配置 API Key？

- 重新运行安装入口（00-点我开始安装.cmd），在菜单中选择配置 DeepSeek API Key 的选项。
- 或者在解压文件夹里双击 恢复或卸载配置.cmd，选择相关配置选项。

======================================================================
三、使用类问题
======================================================================

问：输入 claude 显示"找不到命令"怎么办？

- 可能是 PATH 环境变量没有生效。
- 关掉当前 PowerShell 窗口，新开一个再试。
- 如果还是不行，在解压文件夹里双击 一键诊断.cmd。

问：没有 VS Code 能不能用？

- 能。Claude Code 是命令行工具，在 PowerShell 里直接输入 claude 就用。
- VS Code 是可选工具，不装也不影响本工具的使用。

问：Windows 和 WSL 是不是同一套环境？

- 不是。Windows 版 Claude Code 和 WSL（Linux 子系统）是两套独立的环境。
- 本工具安装的是 Windows 版本，在 PowerShell 里使用。
- 如果你在用 WSL，需要单独在 WSL 里安装 Claude Code。
- 两边的 settings.json 是独立的，需要分别配置。

======================================================================
四、错误码速查
======================================================================

401 — API Key 无效
    检查 Key 是否正确复制、是否过期、是否还有余额。

402 — 余额不足
    充值 DeepSeek 账户。

403 — 权限拒绝
    Key 可能被限制或没有权限。

404 — 接口不存在
    可能是模型名称或 API 地址配置错误。检查配置。

429 — 请求太频繁
    等几秒再试。

5xx — 服务器错误
    DeepSeek 官方服务异常，等几分钟再试。不是您的配置问题。可查看 DeepSeek 官方状态页面。

======================================================================
五、诊断和售后流程
======================================================================

如果遇到问题，请按以下步骤操作：

1. 先不要重复安装。
2. 在解压后的文件夹里双击 一键诊断.cmd。
3. 运行完成后，会在文件夹里生成 support-feedback.txt 和 report.txt。
4. 优先发送 support-feedback.txt 给卖家。
5. 如果没有 support-feedback.txt，再发送 report.txt。
6. 不要只发截图，截图只能作为文字的补充。
7. 不要发送完整 API Key。
8. 不要发送 settings.json。
9. 不要发送 backup/、logs/、reports/、full-report-*。
10. 反馈文件中的 API Key 已自动脱敏处理。

======================================================================
六、哪些文件可以发给卖家
======================================================================

- support-feedback.txt（优先发送，已脱敏）
- report.txt（没有 support-feedback.txt 时才发，已脱敏）
- 错误信息截图（仅作为文字描述的补充，确认截图里没有完整 API Key）

======================================================================
七、哪些文件绝对不要发
======================================================================

- settings.json — 包含完整 API Key
- backup/ 目录下的任何文件 — 可能包含完整 Key
- logs/ 目录下的任何文件 — 可能包含完整 Key
- reports/ 目录下的 full-report-* — 可能包含完整 Key
- 任何包含完整 API Key 的内容

======================================================================
八、本工具提供什么 / 不提供什么
======================================================================

本工具提供：
- 自动安装 Claude Code（Windows 版）
- 自动配置 DeepSeek API 作为 Claude Code 的模型后端
- 一键诊断工具，帮助排查问题
- 使用指南和常用提示词模板

本工具不提供：
- 不提供 Claude 账号
- 不提供 DeepSeek API Key
- 不提供代理 API
- 不提供 VPN 或网络加速服务
- DeepSeek API 使用费用由用户自己的 DeepSeek 账户承担
- Claude Code 本身是 Anthropic 的产品，本工具只负责安装和配置

Claude Code + DeepSeek API 本地配置助手 v1.3.3
先看我：安装说明

======================================================================
一、你会收到什么
======================================================================

你收到的是一个 ZIP 压缩包，里面包含：

- 安装脚本：帮你自动安装 Claude Code，配置 DeepSeek API
- 诊断工具：出问题时帮你生成售后诊断报告
- 使用指南：安装完成后怎么开始用
- 常用提示词模板：复制粘贴就能让 AI 帮你干活

======================================================================
二、安装前先确认
======================================================================

1. 系统需要是 Windows 10 或 Windows 11。
2. 需要有网络连接。
3. 需要有自己的 DeepSeek API Key（在 platform.deepseek.com 注册后获取）。
4. 默认以普通用户身份运行，不需要特意以管理员身份打开。

======================================================================
三、正确安装步骤
======================================================================

1. 先把 ZIP 完整解压到一个普通文件夹。
   注意：不要在压缩包预览窗口里直接双击任何文件！先解压！

2. 如果解压后中文文件名显示正常，双击：
   00-点我开始安装.cmd

3. 如果中文文件名显示异常（乱码），双击：
   Start-Install.cmd
   两个效果一样，Start-Install.cmd 是英文备用入口。

4. 按屏幕提示操作：
   - 选择"一键安装"
   - 等待 Claude Code 自动安装
   - 当提示输入 DeepSeek API Key 时，输入自己的 Key

5. Key 输入时不显示星号或字符，这是正常的安全保护。
   直接粘贴后按回车即可。

6. 安装完成后，屏幕会显示安装摘要和 API 测试结果。

7. 安装完成后，新开一个 PowerShell 窗口，输入 claude --version 确认安装成功，再输入 claude 启动。

======================================================================
四、关于管理员权限
======================================================================

- 默认以普通用户身份运行即可，不需要一开始就用管理员权限。
- 安装过程中某些系统安装器或 winget 可能会弹出 Windows UAC 窗口，只有确认窗口来自可信的 Windows/官方安装流程时才允许。
- 双击没反应不能直接归因于权限问题。先确认已完整解压，检查任务栏是否有被遮挡的窗口，尝试英文备用入口 Start-Install.cmd。
- 以上都试过仍失败，再运行一键诊断.cmd。
- 不要一上来就把"管理员运行"作为首选修复方法。

======================================================================
五、需要你准备什么
======================================================================

- 一台联网的 Windows 电脑
- 一个 DeepSeek API Key（自己去 platform.deepseek.com 注册获取）
- 不需要提前装 Node.js、npm、Python 或任何开发工具
- 安装时间取决于网络和电脑环境，耐心等待即可

======================================================================
六、本工具不包含什么
======================================================================

本工具不提供以下内容，请知悉：

- 不提供 Claude 账号
- 不提供 DeepSeek API Key
- 不提供代理 API
- 不提供 VPN 或网络加速服务
- DeepSeek API 的费用由你自己的 DeepSeek 账户承担

======================================================================
七、安装完成后怎么测试
======================================================================

1. 新开一个 PowerShell 或 Windows Terminal 窗口。
2. 输入 claude --version，确认能看到版本号（版本号具体数字不重要）。
3. 输入 claude 启动 Claude Code。
4. 进入你的项目文件夹，再运行 claude 就可以开始工作了。
5. 详细使用说明请看：02-安装完成后怎么开始使用.txt

======================================================================
八、遇到问题怎么办
======================================================================

1. 先不要在解压文件夹外面乱跑安装脚本。
2. 在解压后的文件夹里双击：一键诊断.cmd
3. 诊断完成后，会在文件夹里生成 support-feedback.txt 和 report.txt。
4. 优先把 support-feedback.txt 发给卖家。
5. 如果没有 support-feedback.txt，再发送 report.txt。
6. 更多问题请看：04-常见问题和售后.txt

======================================================================
九、安全提醒
======================================================================

- 永远不要把完整 API Key 发给任何人（包括卖家）。
- 永远不要把 settings.json 发给任何人。
- 永远不要把 backup/、logs/、reports/、full-report-* 发给任何人。
- 发送诊断文件前，确认发送的是 support-feedback.txt 或 report.txt。
- 不要只发截图，截图只能作为文字描述的补充，无法替代诊断文件。

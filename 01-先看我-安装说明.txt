Claude Code + DeepSeek 本地配置助手 v1.3.3
安装说明
============================================================

你收到的是什么
============================================================

这是一个 Windows 本地安装和配置工具。它可以帮助你安装 Claude Code、
把你自己的 DeepSeek API Key 写入本机配置，并提供诊断、依赖修复和配置恢复入口。

本工具不提供 Claude 账号，不提供 DeepSeek API Key，不提供代理 API，
也不提供 VPN 或网络加速。你需要准备自己的 DeepSeek API Key。

开始前准备
============================================================

1. 使用 Windows 10 或 Windows 11。
2. 保持网络连接。
3. 准备你自己的 DeepSeek API Key，但不要发给其他人。
4. 把收到的 ZIP 完整解压到一个普通文件夹。

不要在 ZIP 预览窗口里直接运行文件。看到压缩包内容后，请先选择“全部解压”。

开始安装
============================================================

1. 打开完整解压后的文件夹。
2. 双击中文入口：

   00-点我开始安装.cmd

3. 如果中文入口显示乱码，改用英文备用入口：

   Start-Install.cmd

4. 默认以普通用户身份运行，不要把管理员权限当作首选解决方案。
5. 如果 Windows 弹出 UAC 权限窗口，请先确认发布者、文件名和操作正是你刚才启动的安装；
   只有确认无误时才允许，内容异常就取消并联系售后。
6. 按窗口提示操作。输入 API Key 时屏幕不显示字符，属于正常的安全保护。

等待安装完成
============================================================

安装时间取决于网络和电脑性能，不承诺固定时长。

1. 窗口持续显示进度时，请继续等待。
2. 不要重复双击安装入口，否则可能同时启动多个安装窗口。
3. 不要直接关闭仍在工作的窗口。
4. 如果窗口长时间没有任何新输出，请按 04 文档中的排查步骤处理。

基础验证
============================================================

安装完成后，关闭旧终端，再打开新的 PowerShell 或 Windows Terminal，依次输入：

   claude --version

能够显示版本号后，再输入：

   claude

如果命令不存在或启动失败，双击：

   一键诊断.cmd

详细使用说明请看：02-安装完成后怎么开始使用.txt

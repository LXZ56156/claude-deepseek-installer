使用方法：打开项目文件夹，在终端运行 claude，然后复制下面的提示词。

============================================================

我要做一个网页前端项目。请帮我规划和开始。

请按下面顺序执行：

1. 检查当前目录：
   - 是否已有 package.json，有的话判断使用什么框架（Vite、Vue、React 等）。
   - 没有 package.json 的话，判断是纯 HTML 项目还是需要框架。

2. 如果是已有项目：
   - 先阅读项目结构，不要直接改代码。
   - 判断启动命令（npm run dev / npm start）。
   - 检查依赖是否完整。

3. 如果是新项目：
   - 给我推荐合适的前端框架和工具。
   - 给出项目初始化方案。
   - 说明每种方案需要的环境和依赖。

4. 检查 Node.js 和 npm 是否已安装。
   - 如果没装，告诉我安装方法。

5. 不要直接执行 npm install。
   - 先说明每条命令的作用，等我确认。

6. 给出发开和测试的方法：
   - 如何本地运行查看效果。
   - 如何打包上线。

7. 先做一个最小可运行版本，能看到页面就行。

输出格式：
- 项目类型判断
- 推荐方案
- 初始化命令和说明
- 启动命令
- 需要我确认的内容

使用方法：进入网页项目文件夹运行 claude，复制本模板全文，并描述页面目标和已有问题。
============================================================

请按以下四个阶段工作。

阶段 A：只读检查
判断这是已有项目、纯 HTML 项目还是框架项目。查看 package.json、锁文件、目录、依赖声明、
Node.js 和实际包管理器版本。尊重已有 npm、pnpm 或 yarn，不更换包管理器，不删除锁文件。

阶段 B：形成判断和计划
根据真实目标给最小方案，不强制 React、Vue 或其他大型框架。说明发现的问题、准备修改的文件、
准备执行的命令、风险和影响、验收方法，并覆盖本地运行、构建、测试、基本响应式、可访问性、
错误状态和浏览器检查。

阶段 C：等待用户确认
不要直接运行 npm install。安装软件或依赖，创建、修改或删除文件，修改配置或环境变量，
发布、付费 API 和破坏性命令都必须先说明并等待确认。

阶段 D：执行和验收
确认后只做已确认范围，逐步检查并实际运行适合项目的测试或构建。有浏览器能力时做实际检查；
无法打开浏览器时如实说明，不能编造“已经在浏览器验证”。报告成功、失败和未解决问题。

安全规则：不泄露 API Key、密码、Cookie、私钥或完整敏感配置；不编造内容；不改无关文件；
不覆盖已有修改，不执行未经确认的删除、重置或清理；命令保持可审查；失败时保留原始错误。

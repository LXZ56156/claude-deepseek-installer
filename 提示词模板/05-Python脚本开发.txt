使用方法：打开项目文件夹，在终端运行 claude，然后复制下面的提示词。

============================================================

我要写一个 Python 脚本。请帮我规划和开发。

请按下面顺序执行：

1. 检查当前目录：
   - 是否已有 .py 文件和 requirements.txt。
   - 有的话先分析现有代码的作用。

2. 检查 Python 和 pip 是否已安装。
   - 输入 python --version 和 pip --version 确认。
   - 如果没有，告诉我怎么安装。

3. 如果需要外部依赖：
   - 建议使用虚拟环境（venv）隔离依赖。
   - 列出需要的 pip install 命令。
   - 不要直接安装，先说明每个包的作用。

4. 如果是新脚本：
   - 确认脚本的目标是什么。
   - 确认输入是什么（文件、命令行参数、用户输入）。
   - 确认输出是什么（打印结果、生成文件、调用 API）。
   - 先给一个最小可运行版本。
   - 确定文件名和运行命令。

5. 不要把一个复杂项目一次写完。
   - 分成可测试的小步骤。
   - 每步完成后先验证。

6. 如果涉及文件操作：
   - 先说明会读取/写入哪些文件。
   - 不要在重要文件上做危险操作（如删除）。

输出格式：
- 环境检查结果
- 脚本目标
- 依赖说明
- 文件名和运行命令
- 需要我确认的内容

使用方法：进入 Python 项目文件夹运行 claude，复制本模板全文，并说明输入、输出和目标。
============================================================

请按以下四个阶段工作。

阶段 A：只读检查
检查 py、python、python3 的实际可用情况和版本，阅读 requirements.txt、pyproject.toml 等依赖声明。
确认现有代码、输入、输出、错误处理和退出码；考虑路径或文件名包含中文及空格的情况。

阶段 B：形成判断和计划
优先使用 venv，区分解释器、虚拟环境和项目依赖，不默认全局 pip install。
说明虚拟环境的创建、激活和退出方式，文件读写明确编码并优先 UTF-8。
列出最小可运行方案、准备修改的文件、准备执行的命令、风险和影响、验收方法。

阶段 C：等待用户确认
安装软件或依赖，创建、修改、覆盖或删除文件，修改配置或环境变量，调用可能产生费用的 API，
以及破坏性命令都必须等我确认。涉及外部 API 时先说明 Key 保护和费用风险。

阶段 D：执行和验收
确认后先完成最小可运行版本，只做已确认范围。逐步检查结果并实际运行脚本和适合的测试，
验证正常输入、错误输入、输出和退出码，报告成功、失败和未解决问题。

安全规则：不泄露 API Key、密码、Cookie、私钥或完整敏感配置；不编造内容；不改无关文件；
不覆盖已有修改，不执行未经确认的删除、重置或清理；失败时保留原始错误和实际验证结果。

使用方法：进入已有项目文件夹运行 claude，复制本模板全文，并说明你想了解的部分。
============================================================

请按以下四个阶段工作。

阶段 A：只读检查
阅读 README、依赖文件、入口、配置示例和相关测试，用实际代码交叉验证 README。
判断启动、构建和测试命令，不运行来源不明或可能修改系统的命令。
先运行 git --version，判断当前目录是否为 Git 仓库；如果是，只读运行 git status。
识别用户已有修改并保护，不回退、不覆盖。

Git 未安装不影响 Claude Code 基础启动，但会影响项目克隆、版本管理、查看改动和安全回退。
Git 是强烈推荐的开发工具；如需安装必须先询问，不要自动安装或配置。

阶段 B：形成判断和计划
输出项目概述、技术栈、主要目录、入口、数据流、启动方式、测试方式和风险。
列出发现的问题、准备修改的文件、准备执行的命令、风险和影响、验收方法。

阶段 C：等待用户确认
先停下来等我确认。安装软件或依赖，创建、修改或删除文件，修改配置或环境变量，
git init、commit、push、发布，付费 API 和破坏性命令都不得提前执行。
不要设置 user.name 或 user.email，不要执行 git reset --hard、git clean 或强制推送。

阶段 D：执行和验收
确认后只做已确认范围，逐步检查并实际运行针对性测试。报告成功、失败、未解决问题和剩余风险，
不要用“应该可以”代替验证。

安全规则：不泄露 API Key、密码、Cookie、私钥或完整敏感配置；不编造内容；不修改无关文件；
不覆盖已有修改，不执行未经确认的删除、重置或清理；命令保持可审查；失败时保留原始错误。

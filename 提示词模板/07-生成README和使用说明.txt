使用方法：打开项目文件夹，在终端运行 claude，然后复制下面的提示词。

============================================================

请帮我的项目生成一份 README 和使用说明文档。

请按下面顺序执行：

1. 阅读项目目录结构和主要文件。
2. 判断项目类型和技术栈。
3. 先给我一个大纲，包含以下内容：
   - 项目简介
   - 技术栈
   - 安装步骤
   - 如何运行
   - 目录结构说明
   - 常见问题
4. 不要编造不存在的功能。
5. 不要假设用户已安装某些工具。
6. 大纲确认后，再生成完整的 README.md 正文。
7. README 要用通俗语言，让非技术人员也能看懂项目是做什么的。
8. 安装和运行命令要可以直接复制使用。
9. 不要泄露任何 API Key 或密码。
10. 如果有配置文件示例，用占位符代替真实值。

输出格式：
- 先给大纲，等我确认
- 确认后生成完整 README

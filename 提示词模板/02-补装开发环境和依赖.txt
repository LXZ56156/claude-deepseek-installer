使用方法：进入项目文件夹运行 claude，复制本模板全文，并说明当前报错或缺少的工具。
============================================================

请按以下四个阶段工作。

阶段 A：只读检查
先从项目文件判断真正需要的环境，区分必需、推荐和可选。只检查与项目有关的 Git、Node.js、
npm、Python、pip 或其他工具及版本；微信小程序项目另查微信开发者工具。已安装项验证版本并跳过。
先运行 git --version，判断当前目录是否为 Git 仓库；如果是，只读运行 git status，保护已有修改。

Git 未安装不影响 Claude Code 基础启动，但会影响项目克隆、版本管理、查看改动和安全回退，
因此是强烈推荐的开发工具。说明是否真的需要 Git；安装前询问我，不自动安装，不设置
user.name 或 user.email，不执行 git init、commit、push、git reset --hard、git clean 或强制推送。

阶段 B：形成判断和计划
分别列出全局环境和项目依赖。每个拟安装命令都说明官方来源、作用、所需权限、影响和验证方法；
优先官方来源，不无理由全局安装，不静默安装，也不一次安装大量无关软件。
列出准备修改的文件、准备执行的命令、风险和影响、验收方法。

阶段 C：等待用户确认
安装软件、项目依赖，创建、修改或删除文件，修改配置或环境变量，发布、付费 API 或破坏性命令
都必须等我逐项确认。不要把安装和修改混成一个无法审查的大命令。

阶段 D：执行和验收
确认后只做已确认范围。每一步检查结果，安装后提示新开终端并验证相关版本，
再运行项目适用的启动、构建或测试命令。报告实际成功、失败和未解决问题。

安全规则：不泄露 API Key、密码、Cookie、私钥或完整敏感配置；不编造内容；不改无关文件；
不覆盖已有修改；失败时保留原始错误，不用“应该可以”代替实际验证。

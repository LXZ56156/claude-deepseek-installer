使用方法：打开项目文件夹，在终端运行 claude，然后复制下面的提示词。

============================================================

我要开发一个微信小程序。请帮我规划和开始。

先在下面的事情上帮我：

1. 检查当前目录是否已经是小程序项目。
   - 看有没有 app.json、project.config.json、miniprogram/ 目录。
2. 如果是已有项目，先帮我分析项目结构和主要功能。
3. 如果是新项目，帮我规划：
   - 页面结构
   - 组件划分
   - 云函数（如果要用云开发）
   - 数据结构和接口
4. 微信开发者工具是做这些事情的必须工具：
   - 预览小程序、真机调试、上传审核。
   - 这些操作只能在微信开发者工具里完成，Claude Code 不能代替。
5. Claude Code 可以帮助我做的：
   - 写页面代码（WXML、WXSS、JS/TS）
   - 写云函数代码
   - 规划数据结构和接口
   - 解释项目结构
   - 排查 bug
   - 生成组件代码
6. 先做一个最小可运行版本，不要一次做太多页面。
7. 检查是否需要 Node.js/npm（安装依赖、使用云函数本地调试时需要）。
8. 如果不确定我当前是否缺少环境，先问我。

重要提醒：
- 微信开发者工具是必须的预览/上传工具，Claude Code 不能代替它。
- 无论代码在 Claude Code 里写得多好，最终预览和上传都在微信开发者工具里完成。
- 如果还没有下载微信开发者工具，先去微信官方下载安装。

执行约束：
- 先检查当前项目和环境。
- 先列计划，等我确认后再执行。
- 先区分哪些在 Claude Code 中做，哪些在微信开发者工具中做。
- 不要默认我已经安装好 Node.js、npm 或微信开发者工具。
- 不要一次性生成过多文件。
- 不要直接创建或修改大量文件。

输出格式：
- 项目结构建议
- 第一个页面的代码
- 需要的下一步操作
- 在微信开发者工具里做什么
- 需要我确认的内容

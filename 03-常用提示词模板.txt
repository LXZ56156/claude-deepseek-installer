Claude Code + DeepSeek API 本地配置助手 v1.3.3
常用提示词模板

这是一份提示词模板索引。提示词模板目录中有 8 个模板文件，每个文件里有一段可以直接复制给 Claude Code 使用的提示词。

======================================================================
使用方法
======================================================================

1. 进入你的项目文件夹。
2. 打开 PowerShell，输入 claude 启动 Claude Code。
3. 打开对应的模板文件，复制模板正文。
4. 粘贴到 Claude Code 对话中，按回车。

注意：只需要复制模板正文即可，"使用方法"这段可以不复制。

======================================================================
模板列表
======================================================================

刚装好后，优先用这个
    文件名：00-先用这个-检查环境和项目.txt
    让 AI 先分析你的项目结构和开发环境，不要一上来就改代码。

接手别人的项目
    文件名：01-接手已有代码项目.txt
    拿到一个不熟悉的项目，让 AI 帮你快速理解结构、入口、依赖和启动方式。

安装开发环境
    文件名：02-补装开发环境和依赖.txt
    项目缺 Node.js、npm、Python 或其他工具时，让 AI 给最小安装方案。

微信小程序
    文件名：03-微信小程序开发.txt
    开发微信小程序时，让 AI 帮你规划页面、组件和逻辑。

网页前端
    文件名：04-网页前端项目.txt
    HTML/Vue/React 前端项目的初始化、结构调整、功能开发。

Python 脚本
    文件名：05-Python脚本开发.txt
    Python 脚本、数据处理、自动化任务的开发模板。

安全修改代码
    文件名：06-安全修改代码.txt
    在已有项目上改代码时的安全流程：先阅读、列计划、确认、再修改。

生成项目说明
    文件名：07-生成README和使用说明.txt
    让 AI 帮你给项目写 README、使用说明、目录结构文档。

所有模板文件都在 ZIP 中的"提示词模板"文件夹里。

======================================================================
安全提醒
======================================================================

- 不要把完整 API Key 发给 AI。
- 不要让 AI 直接读取或输出 settings.json 原文。
- 让 AI 改代码前，先让它列计划。
- 每次只解决一个明确问题。
- 不确定时先问 AI 会怎么做，确认了再让它执行。
- 不要把 settings.json 或完整 API Key 发给卖家。
